# Getting Started

To use this program, you only need to have [Docker](https://www.docker.com/) installed.

### Steps to Run

1. **Build the Docker images**  
  In the root of the project, run:
  ```bash
  docker compose build
  ```

2. **Start the application**  
  Then, execute:
  ```bash
  docker compose up -d
  ```

3. **Access the Web App**  
  Once everything is up and running, open your browser and go to [localhost:8080](http://localhost:8080) to use the application.

  ---

  ### Troubleshooting

  - If you encounter issues, check the logs with:
  ```bash
  docker compose logs
  ```
  - To stop the application, run:
  ```bash
  docker compose down
  ```
